## InputHandler
InputHandler provides a layer between raw input and application logic in the CLI environment..
It standardises how input is entered and allows for the creatio of custom command tokens (e.g. :help).
These are then validated and access their associated functions via a command map. Inputhandler has 
the optional limiting of user input (e.g. restricting responses to a predefined set or type). It
uses while loops to ensure the CLI app avoids crashing when unexpected input is put in.

This folder contains the class Inputhandler and a script with example command maps and usage examples.
